# 最终段落格式

以下为字段模板，尖括号内容需替换为实际剧情；模板本身不能当作已完成分镜。每个镜头都填写全部必需字段。

```text
段落X｜总时长：X.Xs
场景：<起始地点> <时间> <内/外>
出场人物：<实际说话或有主体行为的具体姓名>
本段统一光影/质感：<环境光源、色调、空间材质、空气感和成像质感>

镜N｜X.Xs｜<景别>/<视角>/<构图>
画面：<当前姿态、位置、朝向、视线对象、面部变化、一个主体动作、手部与道具状态>
台词/声音：<角色名>看着<具体对象>说：“<完整台词>”；<必要环境音、拟音和BGM>。
运镜：[起始帧：<具体画面+景别>] -> [关键帧：<具体画面+景别>] -> [结束帧：<具体画面+景别>]

镜N+1｜X.Xs｜<景别>/<视角>/<构图>
画面：<具体可见反应与完整状态>
台词/声音：无台词；<具体环境音或拟音>。<画面人物姓名>闭口。
运镜：[起始帧：<具体画面+景别>] -> [关键帧：<具体画面+景别>] -> [结束帧：<具体画面+景别>]
@
段落X+1｜总时长：X.Xs
场景：<本段起始地点> <时间> <内/外>
出场人物：<具体姓名>
本段统一光影/质感：<完整环境信息>
<逐镜完整填写>
```

## 段内切场

仅在实际切换处、新场景第一镜之前增加独立行：

```text
场景：<新地点> <新时间> <内/外>
```

切场改变环境光时，在新场景镜头中补充 `本镜光影：<环境光线与成像信息>`。段首不并列新旧场景，不增加镜间说明字段。

## 特殊声音写法

- 画外对白：`台词/声音：林霜在画外隔着门板对岁岁说：“先等一等。”画面中的岁岁闭口。`
- OS：`台词/声音：岁岁OS：“她还没有发现。”岁岁闭口，不做说话口型。`
- 旁白：`台词/声音：旁白（画外音）：“那是她第一次见到这座城。”画面人物闭口，不做说话口型。`

OS没有对话对象，不强行套“看着谁说”；普通对白必须明确对象。镜头三帧内部不标秒数，画面变化必须在同一连续镜头可实现。
