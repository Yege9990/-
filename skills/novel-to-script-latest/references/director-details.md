# 导演细则

依据《导演模式最终融合版.pdf》第1–37节整理；用于补充主文件的秒数、表演、光影和构图选择。内容是该文档的执行约定，不代表对参考作品做过独立考证。用户的新要求优先。

## 对白与动作秒数（第9–12、19、31节）

| 台词字数 | 建议时长 | 处理 |
| --- | --- | --- |
| 1–6字 | 1.5–2.0s | 短句落点清楚 |
| 7–12字 | 2.5–3.5s | 保留语气 |
| 13–20字 | 4.0–5.5s | 轻微内部调度 |
| 21–32字 | 6.0–8.0s | 优先对象反应、焦点变化 |
| 33–45字 | 共8.0–11.0s | 拆成2镜，完整保留台词 |
| 45字以上 | 按语义与实际语速 | 拆成2–3镜或按实际需要再拆，不硬压 |

字数只是估算，停顿、情绪、叫喊、专有名词和动作负担会影响时间。超过约6秒或明显转情绪就考虑内部镜头调度；不因标点机械切镜，不以极快语速通过秒数校验。

| 无台词内容 | 建议时长 |
| --- | --- |
| 普通动作 | 0.3–0.6s |
| 普通反应 | 0.3–0.5s |
| 关键反应 | 0.6–0.9s |
| 关键动作 | 0.8–1.2s |
| 爆点动作 | 1.2–1.8s |
| 必要空景 | 0.3–0.6s |
| 新场景建立 | 最多约0.8–1.2s |

短镜只容纳关键变化；不能在0.3秒镜头安排完整走位、拿物、转身和复杂情绪。三帧可描述同一微小动作的起落，不因要求三帧就加入三个大动作。

原PDF第7页的示例标题写14.2秒，但展示的三镜为3.2+2.0+1.0=6.2秒；它只能帮助理解字段与切场，不作为合格秒数模板。实际成品必须重新计算。

## 表演与镜头组织（第6–8、32–36节）

人物入场关注气质、仪态、动作习惯、身份与关系位置。女性人物不只拍脸，身体和手势同样可承载戏；镜头服务人物价值。反派可降低声音、迟迟不眨眼、敲杯沿、摩挲戒指或整理袖口，用空间关系制造压迫；按需要取一个有效动作，避免套路堆叠。

可见表演例子，每镜择取少量要素：

- 愤怒：目光锁定对象，眉心收紧；指尖收拢，肩背由松转硬。
- 委屈：睫毛颤后垂眼，唇线抿紧；手抓住衣角，抬头动作停住。
- 震惊：视线从结果移回对方，眉峰抬起；手停在半空，呼吸断半拍。无台词时闭口。
- 害怕：目光找向门口，肩膀微缩；脚尖向后探半步，手护向胸前。
- 开心：眼神先亮，嘴角再抬；身体前倾或伸手接近目标。

萌娃动作随年龄、人物性格和剧情自然选取，成人戏不强套萌娃表演：

| 部位 | 可选动作 |
| --- | --- |
| 视线 | 偷瞄、抬眼找人、物品转大人脸、被发现后移开、确认安全再看回 |
| 头部 | 歪头、探头、缩脖子、认真点头、听不懂时轻偏头 |
| 手部 | 抠手指、抓衣角、抱紧物品、握拳又松开、两手比划、指尖试碰 |
| 身体 | 踮脚、脚尖内收、小步后退、前倾、靠近可信任者、努力挺胸 |
| 面部 | 抿嘴、轻皱鼻尖、忍笑、鼓腮、眼睛亮起又装镇定 |

对白结构：普通短句用中近景完成一次目光/手势变化；长句可说话人—听者反应—说话人，台词自然跨镜；冲突先双人中景建立距离，再近景互切，情绪落点才用特写或轻推。

萌爽节奏可选：正常铺垫 → 萌娃认真说明与小动作 → 成人短暂停顿 → 萌娃认真补充 → 关键动作/结果 → 反应放大萌点或钩子。只在原剧情适用时使用，不为了套模板新增事件。

## 《逐玉》光影执行约定（第21、28节）

- 低饱和自然底色，以米黄、土褐、灰绿、旧木、蓝灰、冷白为主；不使用糖果色。
- 中等反差、柔和高光，黑位不压死，暗部保留木纹、织物、石墙、烟尘层次。
- 真实环境光：日光、门窗侧光、烛火、灯笼、火盆、雪地反射光。避免无来源面光、塑料影棚感。
- 前中后景可读，浅景深用于分离主体，不能把背景完全糊成色块。
- 可有轻微柔光和空气感，保留真实材质细节，不磨皮、不过度油亮；尊重项目既定2D/3D等画风。

| 场景 | 底色与光源 | 作用 |
| --- | --- | --- |
| 乡野、街巷、日常 | 米黄、土褐、灰绿、旧木；柔和日光，亮部微暖 | 生活感 |
| 室内家庭 | 暖灰、棕褐、亚麻；门窗侧光，保留暗部 | 朴素真实 |
| 雪景、夜景 | 蓝灰、冷白、浅青灰；局部灯笼/火盆暖色，雪保持冷白 | 清冷与暖意并存 |
| 战场、权谋 | 铅灰、暗青、褐黑；适度反差、烟尘、偏硬金属石材 | 压迫、危险、秩序 |

文档中的饱和度降低约10%–20%、高光压低约15%–25%只作参考，不是强制数值。人物面部比环境亮约半档、自然微暖肤色等若需写出，放入“画面”，不能混进环境光影字段。

避免高饱和艳色、重青橙对撞、全画面灰雾、死黑、蓝紫雪地、无来源顶光、过度柔焦、塑料皮肤、油亮反光以及每场套同一冷滤镜。

## 视角与构图（第14、29、32节）

| 视角 | 使用条件 |
| --- | --- |
| 平视 | 默认，日常对白与角色建立，接近人物眼高 |
| 侧前方30°–45° | 克制、偷看、犹豫，保留眼神、鼻梁和下颌 |
| 轻微仰拍 | 决断、反抗、权力显露；不用夸张贴地仰拍 |
| 轻微俯拍 | 受伤、跪地、受困，环境形成压力但人仍可读 |
| 肩后/过肩 | 正反打、试探、秘密、对峙，明确对象与距离 |
| 高位/顶视 | 仅用于包围、队形、动线等必要空间信息 |

| 构图 | 使用条件 |
| --- | --- |
| 稳定三分 | 日常、等待、观察，视线方向留有效空间 |
| 中心 | 重要登场、反抗、身份揭露、高潮；普通对白不连续居中 |
| 对称 | 仪式、家族对峙、审讯、权力秩序 |
| 框架 | 门窗、帘帐、梁柱表现关系阻隔、窥视或私密 |
| 局部前景遮挡 | 秘密、危险、层次；不挡关键动作和口型 |
| 对角线 | 奔跑、打斗、推搡、突然转折，跟随真实动线 |
| 纵深/双人同框 | 高低、远近、关系压力与动作结果，先建立再切单人 |

《糯糯》参考层偏主体清楚、稳定三分或偏中心；与《逐玉》中心构图限制合用时，日常优先稳定三分，重要落点用中心。不要机械交替全景和特写，也不要用连续推近代替有效景别剪辑。

## 声音与生成负担（第16–17、22、36节）

声音可用环境底噪、道具拟音、对白、BGM、留白和跨场声音桥接形成节奏；静音要有情绪或因果目的。OS或画外对白不驱动画内人物口型。反应短而准确，不抢台词。

每镜单一主动作，优先可读的单人或双人，脸、手、物件在必要时可见；不堆多人同时走位和同时发声。情绪张力依靠表演、构图与结果，避免无意义惊吓、血腥细节和视觉噪音。不得为了所谓审核友好擅自删掉用户的重要剧情，应使用忠实且清楚的表现方式。
