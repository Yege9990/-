# 即梦 / Seedance最终段落输出模板

```text
段落X｜总时长：X.Xs
场景：地点 时间 内/外
出场人物：仅写说话或有主体行为的具体人物
本段统一光影/质感：只写环境光线、色调、空间材质、空气感与成像质感

镜1｜X.Xs｜景别/视角/构图
画面：写清当前坐站状态、位置、朝向、主体动作与道具。
台词/声音：角色名看着具体对象说：“完整台词。”
或：无台词；具体环境音/拟音。画面人物闭口。
运镜：[起始帧：具体画面+景别] -> [关键帧：具体画面+景别] -> [结束帧：具体画面+景别]

若本段中途真实切换场景：
场景：新地点 时间 内/外

镜2｜X.Xs｜景别/视角/构图
画面：……
台词/声音：……
运镜：[起始帧：……] -> [关键帧：……] -> [结束帧：……]
@
```

## 规则

- 段落总时长必须等于本段镜头时长之和。
- 段首只写起始场景。
- 一段内若切换地点、时间或内外景，只在切换发生处单独标注新场景。
- 段与段之间用单独一行 `@` 分隔。
- 最终不要增加“镜间说明”“承接上一段”等额外字段。
