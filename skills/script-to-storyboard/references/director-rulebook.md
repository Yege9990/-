# 导演模式完整规则参考

本文件保存“剧本转分镜”skill的完整执行规则。执行剧本转分镜任务时必须与主SKILL.md配合使用。

# 剧本转分镜

## 任务目标
把用户提供的剧本完整转换为可直接用于出图、AI生视频、剪辑、配音与审核的导演级分镜成品。

执行时先做内部导演理解与七列表格母版，但**最终只输出即梦 / Seedance剧情自由时长段落版**，除非用户明确要求查看分析或七列表格。

## 必须遵守的最高优先级
1. 剧情准确、完整覆盖原文，不得概括、省略、跳段、吞台词或擅自改写剧情。
2. 人物状态连续、物理逻辑成立、台词完整清楚。
3. 场景、人物、道具、动作、视线、口型和声音必须可执行、可生成。
4. 时长服从有效剧情，不为了固定秒数凑镜头。
5. 在以上规则全部满足后，再应用《逐玉》滤镜、视角与构图美学。

## 输入
用户通常会提供以下一种或多种内容：
- 完整剧本或分集剧本。
- 小说改编稿或场景台本。
- 人物表、世界观、人设补充。
- 用户对分镜风格、时长、画风、比例、音效/BGM的额外要求。

若用户要求“严格按原剧本”，不得主动增加原文不存在的剧情、人物关系、台词或事件。

## 执行流程
### 第1步：内部导演理解
先在内部判断，不展示给用户：
- 题材与世界观。
- 人物关系与身份差。
- 本场戏的核心目的：立人物、立关系、压迫、打脸、反转、暧昧、爆点、钩子等。
- 视觉中心和情绪中心。
- 哪些台词需要听者反应承载。
- 哪些动作必须拆成可生成画面。
- 爽点、爆点、付费点与结尾钩子。
- 真实需要的镜头数量和时长。

### 第2步：按戏剧节拍拆分
禁止只按大场景粗拆。按戏剧意图和情绪转折拆成更小的节拍单元。

每个节拍尽量具备：
`入场 -> 发展 -> 落点 -> 反应 -> 进入下一个有效动作或情绪`

常见节拍类型：
- 场景 / 角色建立。
- 动作 / 对白调度。
- 关系 / 情绪变化。
- 压迫 / 爆点 / 钩子。

### 第3步：内部七列表格母版
正式输出前，在内部完整覆盖原剧本并生成七列母版：
1. 镜头编号
2. 关联剧本
3. 景别 / 视角 / 构图
4. 画面描述
5. 情绪 & 节奏
6. 声音设计
7. 运镜提示

母版必须从头到尾覆盖原文，不能漏剧情、台词、关键动作、人物状态、道具变化或场景变化。

### 第4步：必要镜头质检
每个镜头至少服务以下两项：
- 叙事
- 角色
- 情绪
- 爽点
- 视觉看点

必须补足：
- 场景与角色建立。
- 动作起势与落点。
- 有效听者反应。
- 爆点保护。
- 结尾钩子。

必须删除：
- 重复表情。
- 重复吃惊。
- 无意义环境镜头。
- 无意义走路。
- 慢推慢停凑时长。

### 第5步：输出最终段落版
只输出可直接执行的即梦 / Seedance段落版，严格使用[输出模板](../assets/output-template.md)。

## 场景建立规则
新场景出现时不能只给一个普通全景。优先采用“宏观 -> 中观 -> 微观”建立环境，并通过物品、声音或视线自然引出人物。

示例思路：
- 现代都市：城市全貌 -> 街道 -> 车窗倒影 -> 车内关键动作。
- 宅斗古风：府邸外观 -> 正院门口 -> 廊下灯影 -> 桌上账册。
- 边关种田：雪原 -> 军户村 -> 破院门槛 -> 泥雪脚印。

新场景建立镜头通常控制在0.8—1.2秒内，迅速进入有效人物或事件。

## 场景切换强制规则
- 每个段落标题只写该段开始时的场景。
- 禁止在段落标题并列两个场景。
- 禁止写“场景1到场景2”“A场景→B场景”等双场景表达。
- 当地点、时间或内/外景真正发生变化时，才在对应镜头前单独写：`场景：新地点 时间 内/外`
- 若之后再次切换，再按同样方式标注。

## 出场人物强制规则
“出场人物”只写本段画面中：
- 实际说话的人。
- 有推动剧情的主体动作的人。
- 有表达剧情意义的关键反应的人。

以下人物不写入：
- 仅在台词中被提及。
- 只作为无剧情功能的背景存在。
- 没有台词、没有主体行为、没有关键反应。

能写姓名时必须写具体姓名。禁止笼统写“三人、两人、几人、大家、众人”。

群体只有在发生集体发声或主体动作并实际影响剧情时，才可用“围观百姓、府兵、街边摊贩”等功能性名称。

## 角色建立规则
主要角色第一次入画时，设计专属人设镜头，至少体现：气质、姿态、眼神、动作习惯、身份压迫感或社会位置、与其他人物的关系位置、当前情绪底色。

角色入场结构：`入场 -> 当前状态 -> 主体动作 -> 有效反应 -> 与下一人物或事件形成关系`

可使用的微动作示例：
- 指尖收紧 / 握住杯沿：克制、紧张。
- 垂眼避开 / 抬眸压人：回避、压迫、权力关系。
- 整理袖口 / 肩背挺直：身份与控制感。
- 坐姿前倾 / 起身逼近：关系推进与空间压力。

### 女性角色
不要只拍脸。根据剧情需要表现身姿、仪态、肩颈、走路姿态、下颌线、手指动作与情绪控制。所有镜头必须服务人物价值，避免无意义凝视。

### 反派角色
禁止只写“冷笑”“阴沉”。可通过声音降低、前景遮挡、空间压迫、构图失衡，以及敲杯沿、整理袖口、摩挲戒指、迟迟不眨眼等微动作制造威胁。

## 动作拆解规则
动作拆镜不是把完整过程逐帧拍完，而是抓：`起势意图 -> 关键过程 -> 落点 -> 物理反馈 -> 角色反应`

普通动作删除无意义过程，保留让观众能够脑补完整动作的关键帧。

## 对白拆镜规则
默认“一句完整台词一个镜头”，不能因为逗号机械切镜。

建议时长：
- 1—6字：1.5—2.0s。
- 7—12字：2.5—3.5s。
- 13—20字：4.0—5.5s。
- 21—32字：6.0—8.0s，优先加入对象反应或焦点变化。
- 33—45字：总时长8.0—11.0s，拆成2个镜头。
- 45字以上：按语义拆成2—3个镜头，不强行压缩。

长台词超过约6秒或内部出现明显情绪转折时，使用：正反打、过肩同框、近景转全景、焦点转换、听者反应、画内音自然转画外音。

长台词画面不能呆，但也不能同时叠加多人复杂交互、大幅走位与复杂手部动作。

## 对话指向强制规则
每一句台词都必须明确：
- 谁看着谁说；或
- 谁对谁说；或
- 隔着什么、通过什么方式对谁说。

禁止只写：`角色名：“台词。”`

画面描述必须同步写清说话人的视线与身体朝向。

特殊情况也要具体：背对、侧对、隔门、隔电话、对着人群、画外音。

## 坐站状态与道具连续规则
同一场剧情尚未结束时，人物的坐、站、蹲、躺、倚靠、行走和手中道具必须逐镜连续。

规则：
- 上一镜站着，下一镜未发生坐下动作：写“仍站在具体位置”，并写清朝向与对象。
- 上一镜坐着，下一镜未发生起身动作：写“仍坐在具体座位”，并写清坐姿与手部状态。
- 姿态发生变化时，必须有“扶桌起身、拉椅坐下、蹲下拾物、放下道具”等明确过渡动作。
- 跨段延续时，新段仍需重新完整写明状态。
- 禁止写“同前”“保持原姿势”“状态不变”。

## 景别 / 视角 / 构图字段规则
第三项只能写纯标签：`景别/视角/构图`

禁止写入人物名、动作、站位、情绪、光影或长句说明。

正确示例：
- `中景/侧前方视角/纵深构图`
- `中近景/肩后视角/双人构图`
- `近景/平视视角/浅景深`

## 三段式运镜强制规则
每个镜头都必须写：
`运镜：[起始帧：具体画面+景别] -> [关键帧：具体画面+景别] -> [结束帧：具体画面+景别]`

三帧要求：具体、连续、不重复、可生成、处于同一镜头的合理运动中，关键帧不能等于结束帧。

运镜内部禁止：秒数、百分比、固定时间点、“继续推进”、“接上个”、“同前”、“状态不变”。

## 声音设计规则
声音字段需根据剧情写清：画内台词、画外台词、OS / 旁白、环境音、拟音、BGM（仅在用户要求或剧情需要时使用；若用户明确不要BGM，禁止添加）、静音、声音桥接。

标准写法：
- 画内台词：`角色名看着具体对象说：“完整台词。”`
- 画外台词：`角色名在画外对具体对象说：“完整台词。”`
- OS：`角色名OS：“内心独白。”画面人物闭口，不做说话口型。`
- 无台词：`无台词；具体环境音/拟音。画面人物闭口。`

## 无台词防张嘴规则
- 所有无台词镜头必须明确写“无台词”。
- 画面人物闭口，只用眼神、手指、呼吸或身体状态反应。
- OS、旁白和内心独白均属画外音，人物闭口，不做说话口型。

## 镜头时长与节奏
无台词镜头保持快节奏，有台词镜头优先保证观众听清。

建议时长：
- 无台词普通动作：0.3—0.6s。
- 无台词普通反应：0.3—0.5s。
- 关键反应：0.6—0.9s。
- 关键动作：0.8—1.2s。
- 爆点动作：1.2—1.8s。
- 空景 / 纯环境：0.3—0.6s。
- 新场景建立：最多0.8—1.2s。

禁止用空景、慢推、慢停或无意义反应凑段落时长。每段总时长必须等于本段所有镜头秒数之和。

## 剧情自由时长段落规则
一个完整动作、对白回合、冲突推进、反转或情绪落点可以独立成段。

每个段落必须自洽地完整写明：段落总时长、起始场景、时间、内/外、出场人物、本段统一光影/质感、人物当前状态、具体动作、台词/声音、三段式运镜。

禁止使用依赖前文的表达：接上个、上一镜、上一段、继续前镜、同前、保持不变。

段与段之间用单独一行 `@` 分隔。

## 光影 / 质感字段边界
“本段统一光影/质感”只允许描述：环境光源、色温、明暗关系、整体色调、空间材质、空气感、成像风格与清晰度。

禁止在该字段写：人物姓名、皮肤、脸部、身材、服装、姿态、动作、人物情绪。

若某镜环境光发生变化，可在该镜画面中补充“本镜光影”，但仍只写环境与成像，不写人物。

## 《逐玉》统一美学规则
### 底层滤镜
- 低饱和自然底色。
- 环境色优先：米黄、土褐、灰绿、旧木色、蓝灰、冷白。
- 不使用高饱和糖果色。
- 对比度中等，高光柔和压住，黑位不压死。
- 暗部保留木纹、织物、石墙、烟尘层次。
- 优先真实环境光：日光、窗棂侧光、烛火、灯笼、火盆、雪地反射光。
- 避免无来源面光与棚拍塑料感。
- 浅景深只用于主体分离，背景结构仍需可辨识。
- 前、中、后景层次明确。
- 允许轻微柔光和空气感，但发丝、粗布、木器、金属、雪粒、皮肤纹理清楚。
- 禁止过度磨皮与油亮高光。

### 四类场景色调
1. 乡野 / 街巷 / 日常：米黄、土褐、灰绿、旧木色；柔和自然日光，亮部微暖，空气清透。
2. 室内家庭戏：暖灰、棕褐、亚麻色；门窗侧光为主，暗部保留，木质与织物纹理清晰。
3. 雪景 / 夜景：蓝灰、冷白、浅青灰环境；灯笼、烛火、火盆形成局部暖色；雪保持冷白，不蓝紫化。
4. 战场 / 权谋：铅灰、暗青、褐黑；低饱和、适度提高反差；烟尘、雾气、金属和石材偏硬。

人物面部若需执行成像控制，可在“画面”里体现：面部比环境高亮约半档、肤色自然微暖、五官与皮肤纹理清楚。不得写入光影字段。

禁止：高饱和艳色、重青橙对撞、全画面灰雾、死黑暗部、雪景蓝紫化、无来源顶光、过度柔焦、塑料皮肤、油亮反光、背景完全虚化、每场都套同一种冷滤镜。

## 《逐玉》视角选择
视角必须服务人物地位、关系距离、动作方向和情绪变化。默认稳定、克制、空间清楚，不为炫技乱换视角。

- 平视：家庭戏、日常交流、普通对话、人物建立。默认视角，接近人物眼高。
- 轻微仰拍：作出决定、反抗、将领登场、战场持械、权力显露。只略低于胸口或眼睛，禁止夸张贴地仰拍。
- 轻微俯拍：受伤、跪地、独处、被围困、处境脆弱。环境形成压力，但不把人物缩成无意义小点。
- 侧前方30°—45°：克制、怀疑、偷看、欲言又止、人物近景。保留鼻梁、下颌与眼神。
- 肩后：正反打、试探、秘密、对峙、观察关系。保留前景肩膀、发丝或衣角，交代距离和视线对象。
- 高位 / 顶视：仅在需要交代包围、队形、动线或命运性空间时使用，禁止作为普通过渡。

## 《逐玉》构图选择
- 三分构图：日常、等待、观察、人物心事。主体落三分线，视线方向留空间。
- 中心构图：开门出现、正面反抗、身份揭露、情绪高潮。只用于重要时刻，普通对话不能连续使用。
- 对称构图：仪式、家族对峙、审讯、议事、权力秩序。
- 框架式构图：阵营分隔、窥视、关系阻隔、私密空间。利用门窗、木梁、帘帐、屋檐形成画中框。
- 前景遮挡：秘密感、危险感、空间层次。只遮局部，不能遮住关键动作或口型。
- 对角线构图：奔跑、推搡、打斗、突然转折。通过人物动线、刀枪、道路、身体姿态形成斜线。
- 纵深 / 双人同框：关系变化、站位压力、动作结果。先用中景建立空间，再进入单人近景，前中后景位置连续。

## 景别与构图组合顺序
一般遵循：
1. 全景或中远景交代人物与环境关系。
2. 中景呈现动作、站位与身体朝向。
3. 近景承接台词、眼神与关系变化。
4. 特写只落在真正的情绪触发点。
5. 动作完成后回到中景，让观众看清物理结果与人物反馈。

情感戏先保留双人空间，再切单人近景。禁止连续推近代替景别剪切。

## AI执行友好规则
优先：单主体、单动作、明确景别、明确构图、明确环境光线、动作落点清楚、前后帧锚点一致。

避免：多人复杂交互、多人同时说话、连续大幅走位、复杂运镜叠加复杂动作、一镜内情绪变化过多。

## 长剧本处理
用户提供长剧本时可以分批输出，但必须：
- 完整覆盖原文。
- 不概括、不省略、不跳段。
- 镜号跨批次连续。
- 不漏人物状态、道具变化、场景变化和说话对象。
- 每批严格按原剧情顺序续拆。
- 每个新段仍完整写明自身信息，不依赖上一批。

若受单次输出长度限制，应在自然节拍处结束本批，并明确下一批从哪个原文位置继续；不得为了赶进度压缩或删减剧情。

## 最终输出格式
严格使用[输出模板](../assets/output-template.md)。

除非用户明确要求，不输出：内部导演分析、七列表格母版、规则解释、额外总结。

只输出可直接执行的分镜成品。

## 最终质检
输出前逐项检查：
- [ ] 原文无概括、无省略、无跳段。
- [ ] 镜号从头到尾连续。
- [ ] 按戏剧意图和情绪转折拆节拍，不按场景粗拆。
- [ ] 出场人物只含说话或有主体行为者。
- [ ] 无“三人、几人、大家、众人”等笼统称呼，除非是有剧情功能的群体。
- [ ] 段首只写起始场景，场景切换只在真实切换处标注。
