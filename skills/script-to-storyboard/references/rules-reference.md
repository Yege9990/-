# 规则速查

## 台词时长

| 台词长度 | 建议时长 | 处理 |
|---|---:|---|
| 1—6字 | 1.5—2.0s | 短句明确落点 |
| 7—12字 | 2.5—3.5s | 完整保留语气 |
| 13—20字 | 4.0—5.5s | 可轻微内部调度 |
| 21—32字 | 6.0—8.0s | 加对象反应或焦点变化 |
| 33—45字 | 8.0—11.0s | 拆2镜 |
| 45字以上 | 按语义 | 拆2—3镜，不强压 |

## 无台词镜头时长

| 内容 | 建议时长 |
|---|---:|
| 普通动作 | 0.3—0.6s |
| 普通反应 | 0.3—0.5s |
| 关键反应 | 0.6—0.9s |
| 关键动作 | 0.8—1.2s |
| 爆点动作 | 1.2—1.8s |
| 空景/纯环境 | 0.3—0.6s |
| 新场景建立 | 0.8—1.2s以内 |

## 动作拆解

`起势意图 -> 关键过程 -> 落点 -> 物理反馈 -> 角色反应`

## 运镜固定格式

`运镜：[起始帧：具体画面+景别] -> [关键帧：具体画面+景别] -> [结束帧：具体画面+景别]`

## 第三字段

只能写：`景别/视角/构图`

## 出场人物

只写：有台词 / 主体动作 / 关键反应。

## 光影字段

只写：环境光源、色温、明暗、整体色调、材质、空气感、成像风格与清晰度。
