# 剧本转分镜

## 用途
把用户提供的剧本完整转换为可直接用于出图、AI生视频、剪辑、配音与审核的导演级分镜成品。

## 执行前必须读取
开始任何剧本转分镜任务前，先读取：
1. [导演规则全集](references/director-rulebook.md)
2. [最终输出模板](assets/output-template.md)
3. 如需快速核对秒数与格式，再读取[规则速查](references/rules-reference.md)

以上资源是本 skill 的强制组成部分。不得只凭通用分镜知识替代其中规则。

## 最高优先级
1. **剧情完整**：原文不概括、不省略、不跳段、不吞台词，不擅改剧情。
2. **状态连续**：人物坐、站、蹲、躺、行走、朝向与手持道具逐镜连续，变化必须有过渡动作。
3. **台词明确**：每句台词写清谁看着谁说、谁对谁说，或隔着什么/通过什么方式说。
4. **物理可执行**：动作、视线、口型、道具、空间关系能直接生成和剪辑。
5. **时长服从剧情**：不靠空景、慢推、重复反应凑秒数。
6. **美学后置**：剧情准确、状态连续、台词完整、物理逻辑和时长规则优先于《逐玉》美学。

## 工作流
### 1. 内部导演理解
内部判断题材、世界观、人物关系、冲突、情绪目标、爽点、爆点、钩子、视觉中心与情绪中心。除非用户要求，不展示分析。

### 2. 按戏剧节拍拆分
按戏剧意图和情绪转折拆成小节拍，不按场景粗拆。节拍尽量形成：
`入场 -> 发展 -> 落点 -> 反应 -> 下一个有效动作/情绪`

### 3. 内部建立七列表格母版
内部完整生成七列：
- 镜头编号
- 关联剧本
- 景别 / 视角 / 构图
- 画面描述
- 情绪 & 节奏
- 声音设计
- 运镜提示

母版必须完整覆盖原文，但最终默认不展示。

### 4. 按导演规则拆镜
重点执行：
- 新场景快速建立世界与空间。
- 主要人物首次入画有人设镜头。
- 动作按“起势意图 -> 关键过程 -> 落点 -> 物理反馈 -> 角色反应”拆解。
- 一句完整台词默认一个镜头；长台词按语义、情绪与听者反应拆镜。
- 出场人物只保留本段实际说话、有主体动作或关键反应者。
- 第三字段只写纯标签“景别/视角/构图”。
- 无台词镜头明确写“无台词”，人物闭口；OS/旁白不做口型。
- 每镜必须有具体、连续、不重复的三段式运镜。
- 光影/质感字段只写环境，不写人物。
- 一段内真实切换地点、时间或内外景时，才在切换处单独标注新场景。

### 5. 应用《逐玉》美学
在不破坏剧情与连续性的前提下应用：
- 低饱和自然底色。
- 真实环境光。
- 中等对比、柔和高光、暗部保留材质层次。
- 前中后景清楚，不把背景完全虚化。
- 平视为日常默认；轻微俯仰、侧前方、肩后、高位只按叙事需要使用。
- 三分、中心、对称、框架、前景遮挡、对角线、纵深/双人同框按关系与动作选择。
- 禁止高饱和糖果色、重青橙、死黑、雪景蓝紫化、无来源顶光、过度柔焦、塑料皮肤、无意义极端角度。

### 6. 输出即梦 / Seedance成品
严格按[最终输出模板](assets/output-template.md)输出。
每段必须完整写明：
- 段落总时长
- 起始场景
- 出场人物
- 本段统一光影/质感
- 各镜头时长与景别/视角/构图
- 画面
- 台词/声音
- 三段式运镜

段与段之间用单独一行 `@` 分隔。

## 长剧本
长剧本允许分批输出，但必须：
- 严格按原剧情顺序续拆。
- 跨批镜号连续。
- 不漏人物状态、道具变化、场景变化、说话对象。
- 每个新段完整自洽，不写“接上个、上一镜、同前、保持不变”。
- 单次长度受限时，在自然节拍处结束本批，并从明确原文位置续接；绝不为了赶进度删减剧情。

## 禁止事项
- 禁止概括、删台词、跳剧情、擅自补剧情。
- 禁止段首并列两个场景或写“场景1到场景2”。
- 禁止无意义群像和笼统“大家/众人/几人”，除非群体动作本身影响剧情。
- 禁止无动作就改变坐站状态或丢失道具。
- 禁止只写“角色名：台词”而不交代说话对象。
- 禁止无台词人物张嘴。
- 禁止用空景、慢推、重复表情凑时长。
- 禁止运镜内部写秒数、百分比、固定时间点或“继续推进/接上个/同前”。
- 禁止光影字段写人物皮肤、脸、服装、姿态、动作或情绪。
- 禁止为了好看破坏轴线、空间、物理结果和人物连续性。

## 完成前质检
逐项确认：
- [ ] 原文完整覆盖，无概括、省略、跳段。
- [ ] 镜号连续。
- [ ] 节拍按戏剧意图和情绪转折拆分。
- [ ] 出场人物筛选正确，无无效背景人物。
- [ ] 场景仅在真实切换处标注。
- [ ] 坐站、道具、位置与朝向连续。
- [ ] 每句台词指向明确。
- [ ] 无台词镜头人物闭口。
- [ ] 光影字段只写环境。
- [ ] 每镜三段式运镜具体、连续、不重复。
- [ ] 段落总时长等于镜头秒数之和。
- [ ] 无空景、慢推、重复反应凑时长。
- [ ] 最终格式完全符合模板。

## 默认最终行为
除非用户明确要求分析、母版或对照表，否则**只输出可直接执行的分镜成品**，不要附加规则解释或总结。
