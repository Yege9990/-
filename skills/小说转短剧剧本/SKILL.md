# 小说转短剧剧本 Skill

## 用途
将用户提供的小说正文改写为可直接拍摄的短剧剧本。

## 默认工作流
用户发送小说正文后，直接输出剧本，不重复规则说明，不先分析，不询问确认。

## 核心规则

### 剧情忠实
- 只以用户提供的小说内容为依据。
- 不补写后续剧情。
- 不提前写结局。
- 用户提供到哪里，就写到哪里并停止。
- 不擅自增加人物、事件、关系。

### 台词保护
- 原小说已有人物台词保持原意和原句。
- 不为了爽点修改关键台词。
- 不把新增内容伪装成原台词。

### 剧情处理
- 保留核心事件、人物关系、冲突、伏笔、爽点、情绪转折。
- 压缩重复文学描写，不删有效剧情。
- 同一个事件只表现一次，不重复制造冲突。

## 短剧节奏

目标：开场抓人、节奏快速、逻辑顺滑。

优先结构：
强钩子 → 冲突建立 → 信息推进 → 矛盾升级 → 人物反击 → 情绪释放 → 新悬念

不得为了卡点增加原文不存在剧情。

## 影视化改写

小说叙述转换为：
- 动作
- 表情
- 场面调度
- 道具信息
- 必要OS

减少长篇旁白，增加可拍画面。

心理描写优先转化为行为和反应，无法表现时使用OS。

## 输出格式

第一集：标题

1-1 场景名称 日/夜 内/外
人物：人物列表

△动作、环境、人物状态。

人物（情绪）：台词。

△继续推进剧情。

支持：
- 多场景编号
- 闪回
- OS
- 情绪标注

## 风格要求

- 强冲突
- 高信息密度
- 快节奏
- 强视觉
- 可直接拍摄
- 人物行为塑造性格

重点强化原文已有：
- 身份反差
- 误会
- 羞辱
- 反击
- 证据反转
- 情绪爆发

但不能脱离原文。

## 最终输出原则

用户发送小说：
1. 直接输出剧本。
2. 不解释改编过程。
3. 不总结剧情。
4. 不续写未来剧情。
5. 写完本次小说内容立即停止。

核心原则：
忠于原文 > 节奏强化 > 影视化表达 > 爽点包装。
